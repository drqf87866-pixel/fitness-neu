# AGENTS.md

German-language, mobile-first fitness-tracker PWA. React 19 SPA + Hono API in a single Cloudflare Worker (entry: `src/worker/index.ts`), D1 (SQLite) via Drizzle, built by one Vite config (`@cloudflare/vite-plugin`). Full docs live in `README.md` (German).

## Commands

- Package manager is **pnpm**. This is a single package — `pnpm-workspace.yaml` is not a monorepo, it only sets `allowBuilds` (esbuild, workerd).
- First-time local setup, in this order: `pnpm install` → `cp .dev.vars.example .dev.vars` → `pnpm db:migrate:local` → `pnpm db:seed` (seed only after migrate; seed is idempotent `INSERT OR IGNORE`).
- `pnpm run dev` runs frontend + worker + local D1 together. Do not run `wrangler dev` separately.
- **`pnpm typecheck` (`tsc --noEmit`) is the only QA gate.** There are no test, lint, or format scripts — don't look for them.

## Schema changes

Edit `src/db/schema.ts` → `pnpm db:generate` (creates migration in `drizzle/migrations/`) → `pnpm db:migrate:local`. For remote: `pnpm db:migrate:remote`, then `pnpm db:seed:remote` if catalog data changed.

## Architecture notes

- All backend routes live under `/api/*` in `src/worker/routes/` and are registered in `src/worker/index.ts`. `run_worker_first: ["/api/*"]` in `wrangler.jsonc` sends only those to the worker; everything else is SPA assets.
- `authMiddleware` (`src/worker/middleware/auth.ts`) guards every `/api/*` route except `/api/auth/login|register|logout` via session cookie and sets `userId` on context — new API routes get auth for free.
- Shared Zod schemas/types in `src/shared/`. Path aliases (vite + tsconfig): `@/` → `src/client/`, `@shared/` → `src/shared/`.
- Worker env typing: `Cloudflare.Env` is declared in `src/env.d.ts`. `worker-configuration.d.ts` (generated by `pnpm cf-typegen`) is gitignored and need not exist despite the tsconfig `include` entry.
- Daily cron (03:00 UTC) in the worker's `scheduled` handler deletes expired sessions and rate limits.

## Gotchas

- Service-worker caching is deliberately minimal: only `GET /api/exercises` is cached (NetworkFirst, 1h). Auth/session/analytics must stay network-only — read the comment in `vite.config.ts` before touching `runtimeCaching`.
- Offline workout sets queue in IndexedDB (db `fitness-neu`) and sync later.
- UI copy and error messages are German — keep user-facing strings German.
- `GEMINI_API_KEY` is optional (`.dev.vars` locally, `wrangler secret put` remotely); AI plan generation falls back to a heuristic plan without it.
- `scripts/` is one-off exercise-image/icon tooling (sharp, PowerShell, Python), not app code.
- Deploy: `pnpm run deploy` (build + `wrangler deploy`), requires `wrangler login`.
